1. Pengertian Algoritma & Ciri-cirinya

Algoritma adalah urutan langkah-langkah logis dan sistematis yang digunakan untuk menyelesaikan masalah tertentu atau mencapai suatu tujuan. Syarat algoritma yang valid antara lain:

• Definiteness (Kepastian): Setiap langkah harus terdefinisi secara jelas dan tidak bermakna ganda.
• Finite (Keterbatasan): Memiliki titik awal (*start*) dan titik akhir (*end*).
• Input & Output: Memiliki data masukan awal yang diproses untuk menghasilkan luaran/hasil.

2. Studi Contoh: Algoritma Hitung Luas & Deteksi Bangun Datar

Berikut adalah algoritma nyata untuk menghitung luas bangun segi empat serta menentukan apakah bangun tersebut dinamakan **Persegi** atau **Persegi Panjang** berdasarkan kondisi nilai panjang dan lebarnya:

A. Deskripsi Algoritma & Pseudocode

// Pseudocode Percabangan Bangun Datar

START

  INPUT panjang, lebar

  Luas = panjang * lebar

  IF (panjang == lebar) THEN

      nama_bangun = "Persegi"

  ELSE

      nama_bangun = "Persegi Panjang"

  ENDIF

  PRINT nama_bangun, Luas

END

B. Flowchart Hasil Konversi

[START] Mulai
Input (Panjang, Lebar)
Luas = Panjang × Lebar
Apakah Panjang == Lebar?
[YA]
Nama = "Persegi"
[TIDAK]
Nama = "Persegi Panjang"
Cetak (Nama, Luas)
[END] Selesai

3. Simbol Standar Flowchart

Oval
Terminator:

Menandai awal (Start) atau akhir (End) dari suatu aliran proses.

Jajaran Genjang
Input / Output:

Digunakan untuk menerima masukan data atau menampilkan hasil cetakan.

Persegi Panjang
Process:

Menyatakan operasi penghitungan aritmatika atau pengolahan data.

Belah Ketupat
Decision (Keputusan):

Percabangan kondisi logika (misal: membandingkan Ya / Tidak).

  2. Sistem memeriksa ketersediaan data pada database.
